Wenn der Parameter x_extra auf 1 gesetzt ist, werden nur Neugeräte an den EDI-Partner übermittelt.
Möchte man alle Geräte übermitteln, inklusive Refurbished, so muss bei dem Job-Aufruf x_extra auf 0 gesetzt werden.

Fall spezieller Titel

Wird vom EDI-Partner ein verkürzter oder spezieller Produkte-Titel gewünscht (z.B. Galaxus), so kann dieser im exclude-Wert title eingepflegt werden.

Restock-Date

Wenn der Lagerbestand mit 0 angegeben wird, aber das Restock Date das Tagesdatum ist, geht das Galaxus-System davon aus, dass der Artikel verfügbar ist und stellt ihn auf dem Marktplatz noch dar. (s. E-Mail v. Momme 02.07.2024, 13:52)

E-Mail v. Chiara.Weilenmann@digitecgalaxus.ch (11.10.2024, 18:15)
Mir ist soeben aufgefallen, dass ihr uns viele veraltete Restock Daten im Bestandesfeed übermittelt. Solange ihr Ware an Lager habt wird der Wert nicht gezogen. Wir brauchen aber trotzdem verlässliche Restock Daten – wenn ihr keines habt bitte auch kein Restock Datum ausweisen.

Spalte in Export-Datei: RestockDate, Format: TT.MM.JJJJ
