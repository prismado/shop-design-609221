WordPress

Ihr Hosting-Anbieter kann Ihnen mitteilen, ob ein persistenter Objekt-Cache für Ihre Website aktiviert werden kann. Ihr Webhosting scheint die folgenden Dienste für das Zwischenspeichern von Objekten zu unterstützen: APCu (Alternative PHP Cache User = PHP-Erweiterung).

Für WordPress wird das Plugin "Redis Object Cache" und die Installation von redis auf dem Linux Server benötigt. 

apt install redis-server -y
Erfahren Sie mehr über das Zwischenspeichern persistenter Objekte.
