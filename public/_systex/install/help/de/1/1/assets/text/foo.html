Neuen Benutzer erstellen

  1. Öffnen Sie einen Browser im Incognito-Modus oder einem eigenen Profil
  2. Klicken Sie oben rechts auf Anmelden
  3. Klicken auf Registrieren
  4. Füllen Sie die Felder aus und klicken Sie auf Registrieren

Neuen Administrator erstellen

  1. Öffnen Sie nach der Registrierung (obere Schritte) als Administrator die Kundenfunktion und öffnen Sie den Benutzer
  2. Aktivieren Sie die Checkbox "[ X ] Admin"
  3. Klicken Sie auf "Update"
